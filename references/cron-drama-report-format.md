# 追剧定时报表口径

本参考文件记录 `report_drama_status.py` / `list-drama-state.py` 的当前输出口径，避免后续回退成只报“有无更新”的简版。

## 输出目标
- 不管今天有没有更新，都要输出**全量追剧列表**。
- 报表要能直接看出：
  - **本地已有多少集**（`current_episodes`）
  - **当前绑定源目录可见多少集**（`source_entries`）
  - **今日新增多少集**（`max(0, source_entries - current_episodes)`）
  - **差值多少集**（当本地进度大于源目录时，标记为源端残缺/旧源）
  - **总集数**（`total_episodes`）

## 推荐表头
| 类型 | 剧名 | 本地进度 | 源目录 | 今日新增 | 差值 | 总集数 |
|------|------|----------|--------|----------|------|--------|

## 规则
- `current_episodes` 代表本地 STRM/库里实际进度。
- `source_entries` 代表当前绑定源目录里可见的视频集数。
- `今日新增` 只统计源目录比本地多出来的部分，不能只靠过去是否更新来猜。
- `差值` 用于提示源端残缺或绑定错源；不要把它当成任务失败。
- 电视剧 / 综艺 / 动漫 / 电影 / 纪录片 要分类型汇总。

## 常见坑
- 只输出“今日无更新”会让用户看不见全量状态，后续不好核对。
- 目录文件数不等于唯一正片集数；遇到 `4K`、`1080P`、预告、花絮、重复转存，要先去重再算。
- 完结条目应由校准脚本移出 active 列表，不要在报表里继续当进行中显示。
